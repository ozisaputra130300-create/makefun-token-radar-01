Token Radar (radar-2): a comparables-calibrated launch radar. It reads the sealed DefiLlama snapshot of 758 protocols, ranks all 198 rankable pre-token protocols — the whole 40-protocol watchlist plus 158 more below the floor — by an implied launch value priced from the snapshot's own live-token peers, and hands in a dashboard with a sortable, filterable board, a detail view with the model's factors for every protocol, and a farm plan with costs and times on every row.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
